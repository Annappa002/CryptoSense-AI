## 🚀 Quick Start

### Installation

1. **Clone the repository**
```bash
git clone <repository-url>
cd flask_ml_app
```

2. **Install dependencies**
```bash
pip install -r requirements.txt
```

3. **Run the application**
```bash
python app.py
```

4. **Access the dashboard**
Open your browser and go to `http://localhost:5000`
